# Blood terrain

## Data-driven weapon economy

Class baselines per trigger: handgun 1.2, PDW/SMG 0.6, shotgun 9.5, DMR/sniper 15, carbine 1.5, LMG 1.3. Class stencil radii are 32 / 32 / 160 / 96 pixels respectively (1 / 1 / 5 / 3 chunk-widths). These are spatial extents, not commands to fill entire storage chunks. A platform may override `blood_cost` and `stain_radius`; the resulting GunData remains authoritative. Runtime radii are copied into each bullet and DamageContext, including the terminal death burst. GunData inspector groups expose Blood Cycle Economy. Dry firing at insufficient reserve has a 0.2-second cooldown. Enemies retain their original gun-ammo compatibility path.

Projectile dispatch now duplicates the equipped GunData into a launch-time snapshot carried as DamageContext.weapon_source. Consumers treat this resource as read-only. The radius scalar also reaches terminal death effects; switching/modifying the live gun cannot change in-flight painting. Penetrating bullets keep their existing remaining-mass ledger instead of being destroyed at the first actor.

Performance caveat: a standalone unoccluded radius-160 shotgun stencil measured approximately 35 ms in the latest local headless test (previously approximately 49 ms). Scanline chunk caching reduces repeated dictionary lookups while retaining synchronous per-pixel deposition, wall clipping, saturation and pollution removal. This is not a 60-FPS worst-case guarantee. Amortized painting remains deferred: it must first account for siphoning during pending deposits, rather than allowing already-drained terrain to regenerate from stale jobs.

- Player feet sample the sparse ground canvas, not wall blood or rendered textures.
- Crimson: 1.30x walking speed. Rolls resample the exact pixel underfoot before every physics movement step: crimson grants 1.35x roll speed, leaving it or siphoning it restores 1.00x. The walk multiplier does not stack with the roll bonus. Duration (0.28s), invulnerability (first 0.18s), cooldown and wall collision do not change. Eight visual-only crimson pixels show the boosted roll without creating absorbable blood. Ordinary floor: 1.00x. Gray striped contamination: 0.60x walking and no roll initiation; an existing roll is not cancelled by entering it.
- Right-mouse siphoning does not add a movement penalty. Removing the blood underfoot removes its speed bonus.
- Current siphon: invisible 90-degree forward sector, reach 224 world pixels; 48-pixel omnidirectional proximity circle. Both share the same resource budget, respect solid/vision-blocking geometry and exclude contamination. A bounded round-robin traversal drains multiple chunks together. Near motes arrive in roughly 0.075–0.13 seconds, distant ones up to 0.48 seconds. A small crimson cursor halo indicates actual absorption, not merely holding the button. Gain is credited once on removal; particles are visual only.
- New runs start with 100 blood. Floor transitions/retries restore the run checkpoint rather than refilling. GunData.caliber_blood_cost and blood_stain_radius are generated from weapon-class baselines, with per-platform overrides. One trigger pull pays once, including pellet weapons. Blood-ammo mode disables legacy Q/E/R abilities, B healing, X Focus and ammunition-box spawns, but keeps Q throw and E pickup. Legacy APIs remain for non-blood modes/tests; this is not a deletion of every historical system.
- Every eighth eligible authored spawn (index 5 modulo 8, excluding dogs) is a contamination carrier, identified by grayscale twin canisters. It keeps the underlying patrol/combat AI. Hits leave a radius-12 patch, limited to once per 150 ms; death leaves radius 23. No absorbable blood or wound trail comes from this variant.
- Contamination lives in a separate byte plane inside existing 32x32 chunks. It never credits blood currency. Incoming blood clears its pollution bit permanently; siphoning that blood reveals clean floor, not the old hazard.
- SMG/PDW impact and terminal splatters use separated dots. Existing weapon wound intensity still affects reach and density.
- Shotgun kills add an opaque, low-mass forward fan using the configured radius (class baseline 160 pixels). Exiting sniper wounds add a 3-pixel-wide route up to 320 pixels, stopped by solid walls. These are gameplay units, not claimed real-world distances. Existing weapon damage/penetration profiles still determine whether an exit wound occurs.
- Explicit empowered-blood budgets include these footprints. Normal hit generation continues the existing enemy-blood economy; long-run sustain balancing still needs playtesting.

Tests: test_blood_terrain covers negative world coordinates, speed states, roll restriction, non-absorbable pollution, permanent overpaint, footprint direction, mass caps, and solid-wall clipping. Renderer fixture adds blood_terrain.png. Neither is a substitute for a full human run.
